
# 🎮 Anúncio de Controle — Landing Page PlayStation

Projeto de uma landing page para divulgação de um controle de PlayStation 4, desenvolvido com **HTML5, CSS3 e JavaScript** como parte de uma atividade prática do curso PROA.

O projeto tem como objetivo explorar a criação de páginas promocionais modernas e responsivas, utilizando efeitos visuais, animações interativas e um layout que destaca o produto e suas informações.

## Funcionalidades e características

- Landing page promocional de um controle para PlayStation 4.
- Exibição de informações, preço e imagem do produto.
- Botão "Compre agora" com animação ao passar o mouse.
- Área visual com gradiente e opção de adicionar ao carrinho.
- Menu de navegação adaptável para dispositivos móveis.
- Menu mobile expansível utilizando JavaScript.
- Ícones de redes sociais e layout organizado em duas colunas.

## Tecnologias utilizadas

- **HTML5:** estruturação da página e dos elementos do produto.
- **CSS3:** estilização, gradientes, animações e organização do layout.
- **JavaScript:** controle da abertura e do fechamento do menu mobile.
- **Flexbox:** alinhamento e distribuição dos elementos.
- **Media Queries:** adaptação da interface para telas menores.
- **Google Fonts:** utilização da fonte Poppins.

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Criação de layouts promocionais utilizando HTML e CSS.
- Organização de conteúdos em colunas com Flexbox.
- Aplicação de gradientes e elementos decorativos com `::after`.
- Desenvolvimento de efeitos de hover e transições em botões.
- Implementação de menu mobile interativo com JavaScript.
- Utilização de Media Queries para adaptar o layout.
- Manipulação de estilos com `getElementById` e `maxHeight`.
